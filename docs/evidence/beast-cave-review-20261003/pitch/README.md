# Beast Cave pitch shorts (2026-10-03)

- `beast-cave-pitch-15s.mp4`: 15.0 s, 1080×1920, 24 fps, silent
- `beast-cave-pitch-10s.mp4`: 10.0 s, 1080×1920, 24 fps, silent

## How they were made (provenance)

1. **App home**: a real screenshot of `index.html` (phone layout). The push-in is done in ffmpeg on the exact pixels, with no AI.
2. **Room shots**: six real 1080×1920 renders of the Beast Cave from the app (`?reviewRoom=beast-cave`), with UI hidden.
3. **Camera motion**: each room still was animated with Higgsfield → Kling 3.0 (pro, image-to-video, 5 s, sound off). The prompts asked for camera moves only, with no new objects, text, people or logos. Job IDs:
   - door `37613fe1-29c1-49d4-83cb-6af6c5ac0ac2`
   - hero `a6bc766b-cd33-4296-86a0-47e2f8a6dd3a`
   - neon `4ab14c4c-29b7-406d-955e-2b2245dbd5e5`
   - ride `32b94e77-0805-475b-85dd-73d152f39657`
   - gap `781a8629-51c1-42b3-b0e2-be00259095d1`
4. **Rejected**: the orbit clip (`437de8f9-…`) invented a different bike (drop bars) and is not used.
5. **Edit**: ffmpeg grade (contrast, warm highlights, vignette, light grain) and 0.3 s crossfades.

**Disclosure.** Scene content comes from the app. Camera motion in the room shots is AI-interpolated from those frames, so call it "motion from app renders", not a screen recording. No athlete likeness, no Zwift UI, no brand marks.
