# ROTAVERK · The anatomy of cycling (working name)

Status: architectural incubation, not public/production. Name is provisionally constructed from Latin *rota* (wheel) and Swedish *verk* (works); formal trademark/domain clearance pending.

**Mission:** Source-backed bicycle identity, mechanical anatomy, cross-year comparison, history, documentation and maintenance utility. Later: local-first Garage, moderated Q&A, trusted seller/service network and transactional marketplace only after validation.

## Why this directory exists
KONA.m already has a canonical Product source, 3D asset manifests, bike schema, global machine-inspection kernel and event/room integration contracts. The future standalone platform should emerge from this foundation rather than fork it. This incubator holds strategy and independent **read-only** verification tooling without production imports, new renderer/identity authority, or public UI changes. A separate project can be extracted only after canonical ownership transfer is explicitly planned, tested and approved.

## Initial code
The `bridge/` directory contains dependency-free node read-only catalogue auditing and evidence-first tri-state compatibility utilities, not a new bike data store. Execute `node --test incubation/rotaverk/bridge/test.mjs` and `node incubation/rotaverk/bridge/audit.mjs museum/catalog/products.json` in repo root.

The current GitHub catalog is generated by `tools/build_catalog.mjs`, not edited by this prototype. KONA's `docs/architecture/AUTHORITY_MAP.md` prevails if anything conflicts.

## Not included
No services, payments, forum writes, OAuth, user data, public deployment, claimed manufacturer partnership or verified CAD. The full standalone prototype bundle is available in the originating ChatGPT session; this PR contains only source-compatible review artifacts.
