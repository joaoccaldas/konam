## Changes

- Text-aware private-data scanning strips opaque embedded base64 payloads while scanning surrounding tracked text.
- Landing install utility restyled as quiet inline utility.
- Mobile navigation flattened to deterministic app chrome with a small active indicator.
- Home extracted to web/src/ui/home.js and reduced to:
  - one current moment
  - one primary action
  - one editorial discovery object
- Discover extracted to web/src/ui/discover.js.
- Discover now loads integrations/public-catalog.json only after Discover intent.
- Discover does not import museum-data.js, hall.js, __ROOMS, __BRANDROOMS or __gallery.
- 3D remains an explicit "Enter the world" action.
- Visual matrix expanded to Light / Dark / Random and Landing / Home / Discover / Garage / Plan / Me.
