# Artifact Experience V1

One presentation contract for bikes, shoes, helmets, watches, wheels, wetsuits, components and memorabilia.

Hierarchy:
1. Artifact identity
2. Beautiful object
3. 3–4 useful facts
4. One dominant action
5. Progressive disclosure

Primary action is Inspect when 3D exists. Commerce is never the visual or ranking authority.

Mobile: object remains visible; information rises as a bottom sheet.
Desktop: object dominates; exhibit information occupies a restrained panel.

Tabs: Overview · Engineering · Race history · Gallery.

This contract replaces per-brand product-page invention. Room atmosphere may differ; Artifact interaction does not.
