# Visual, evidence, safety, security and release requirements

## Visual system
Premium Scandinavian engineering archive: warm sand `#F3F1EC`, ink `#162024`, dark engineering stage `#11191B`, restrained metal `#CBB48A`, sea-glass `#87B6A9`. Use compatible KONA tokens first rather than create a second brand system in the consumer shell. Manrope for controls; Instrument Serif for editorial; mono for measurements/provenance. Large negative space, technical labels, no generic dashboard card wall.

Primary public navigation: Explore / Compare / Learn / Maintain / Collections. Optional authenticated Garage; Q&A and commerce contextual, not frontdoor. Detail page: product identity → 2D first useful content → optional 3D → measurements → mechanics → history → manuals/sources → future verified offers. Exploded part click opens manual/part provenance, not random spectacle. Keyboard, accessible part list, reduced-motion, 360px mobile portrait and landscape all required.

## Data quality
- No model/trim/size conflation. Every price/weight/measurement has unit, source, applicable model and checked date.
- "Compatible" requires exact verified condition and manufacturer/source support; otherwise "unknown".
- A reconstructed silhouette is not dimensionally certified; label verified/reference-calibrated/original study/concept.
- Historical race/athlete associations need independent source and correct time/version. Source dates ≠ model year.

## Safety/security
- No invented torque, recalls, fluid, service intervals or carbon repair; manufacturer instructions and professional-service warnings prevail.
- License and archive-rights review for manuals, logos, photos, GLBs and datasets. Never copy third-party materials without permission.
- Strava, Samsung, training, medical or private garage records must stay separate/owner scoped, exportable and deletion supported, with explicit scopes/consent.
- Future forum: active moderation, reporting, blocking, content safety and provenance; external posts never become canonical manufacturer facts.
- Future marketplace: seller verification, product authenticity, stolen-bike prevention, EU DSA/GPSR/legal review, dispute, refunds, payment provider and fraud procedures before launch.
- No implied manufacturer partnership, automatic purchase, merchant email or unaudited external publication.

## Quality gates
Baseline SHA, 100% stable IDs, claimed source coverage quantified, duplicate variants detected, zero unjustified compatibility positives, no UI overflow, screenshot evidence, real Android review, keyboard/a11y, memory/transfer/frame-time measurements, exact SHA CI and rollback plan. Source-file inspection ≠ tested ≠ deployed.

## R&D instrumentation
Track first correct useful content, first correct 3D frame, compressed bytes, render p50/p95, draw calls, GPU memory estimate, hit-testing correctness, user-task correctness/latency and actual support/commerce outcomes. If missing, mark UNKNOWN, never estimate as fact.
