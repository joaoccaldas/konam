# Home + RaceIdentity V1

## First visit

One proposition:
**Race the version of yourself.**

One primary action:
**Build my race self**

Then sequentially:
1. Why are you here?
2. What would you race?
3. What would you wear?
4. What are you chasing?
5. Reveal

No account before payoff.
No 3D before Explore.

## Return visit

Do not replay onboarding when a valid RaceIdentity exists.

Home prioritizes:
1. race countdown / context
2. next useful action
3. RaceIdentity completion
4. challenge/collection progress
5. one fresh discovery
6. resume recent object

## Empty-state rule

Me/Garage/Passport zero states must tell the user what action creates value.
Never show an empty dashboard without a next step.

## Reward rule

RaceIdentity creation can reward XP/Credits through the existing progression event contract.
UI does not mutate balances directly.
