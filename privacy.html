Privacy & data in this beta

Updated 3 October 2026. Kona.m is an independent public beta. Public email sign-in is unavailable until production email delivery and account-support arrangements are ready. You can use the app without an account.

On your device

Your avatar, optional name, answers, race goals, equipment, discoveries and preferences are saved in this browser. We do not request medical records. On the public GitHub Pages beta, Kona.m uses privacy-minimal first-party product analytics to count page views across public pages, anonymous session-level interactions, a 15-second engagement signal, binary product feedback and coarse runtime-health events. For first-touch attribution it stores the landing pathname, external referring hostname when present, optional UTM campaign values, and a coarse traffic class (public, QA or browser automation). Runtime-health events use allowlisted categories such as renderer, navigation, storage or feed failure plus the sealed app release ID and online/offline state; they do not send raw error messages or stack traces. It uses a random ID limited to the current browser session; it does not use advertising cookies or a persistent cross-session visitor ID, and analytics is not linked to your email, account, RaceIdentity or free-text feedback. The packaged native app does not enable this public-web analytics path. Export device data creates a local file; Delete device data removes app-owned browser records, including local authentication state. It does not delete a cloud backup or account.

Optional cloud records

Existing signed-in beta users can manually back up their game state to Supabase. A backup can include an uploaded avatar image, goals and equipment. Backups are linked to the signed-in account, restricted to that account, and remain until replaced or deleted. Delete cloud backup in Progress removes the active saved state; it does not remove the Auth account or immediately purge provider operational backups/logs. Account erasure and retention procedures have not yet been cleared for public account launch.

Public services

GitHub Pages serves this site. Google Fonts loads typography, Wikimedia and YouTube can serve images, and requested weather/news features contact public providers through the app or Supabase. These providers receive request information such as IP address. Kona.m sends the public-web analytics events described above to its Supabase project; the analytics table stores no IP address, user agent, email, account ID, precise location, full referrer URL, raw feedback text, raw error message, stack trace or persistent visitor identifier. The analytics Edge Function may inspect an IP transiently for abuse rate limiting without storing it in the analytics table. Analytics events are automatically deleted after 30 days. Videos and external links open at their provider; nothing autoplays. Loading an image is not equivalent to being fully offline or making no network requests.

Scope and support

This is an interim behavior notice, not legal clearance. A verified operator/contact, processing basis, retention schedule and applicable international-transfer/rights process must be published before public account registration is enabled. Do not put personal details in public repository issues. Source and non-personal bug reports can use the public project repository. Public athlete and photographer names appear only where they are legitimate editorial subjects or required source attribution; private contributor identities are not part of the public product surface.
