# Portfolio read-only projection

Canonical sources: `museum/catalog/products.json` (generated by `tools/build_catalog.mjs`) and `app/admin-assets.json` (generated by `tools/build_admin_assets.mjs`). This is a **derived view**, not a database or source of rights/approval truth.

```sh
node tools/portfolio-projection.mjs museum/catalog/products.json app/admin-assets.json > /tmp/portfolio-projection.json
node --test web/test/portfolio-projection.test.mjs
```

The output supports search cards and integration snippets with stable source IDs, source product viewer URLs, GLB relative paths, finish variants and room placements. Null actions mean unavailable; unknown room IDs are explicit. Preview stays `unverified` and rights `not-reviewed-in-projection` until a reviewed source supplies evidence. Do not expose this projection as an authenticated asset endpoint without independent server-side authorization; a static URL is public. Never auto-promote entries to production from these cards.
