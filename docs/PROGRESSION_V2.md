# Progression V2

## Benchmark-derived principles
- Zwift: first-completion route badges make exploration collectible.
- NRC: challenges and achievements celebrate meaningful milestones.
- Strava: group challenges add accountability and connection.

KONA should not copy mileage leaderboards. Its native game is **identity + discovery + mastery**.

## Four loops
1. Discover: place / story / artifact / room.
2. Collect: fixed relics and themed sets.
3. Master: challenges and personal bests.
4. Become: RaceIdentity, confirmed history, setup completion and Passport.

## Reward integrity
Never reward affiliate clicks.
Never reward a share-button tap.
Never randomize paid rewards.
Never lock safety, compatibility or essential race information.
Referral rewards require a future server-verified completed RaceIdentity.

## Relics
V2 starts with 20 original symbols across:
- Kona Elements
- Aero Revolution
- Race Day Relics
- Hidden Engineering

The registry explicitly avoids replicas of sacred or culturally restricted Native Hawaiian objects.

## Unlocks
Unlocks add delight rather than withholding utility:
- cosmetics
- additional dream-equipment slots
- historical/secret rooms
- challenge variants
