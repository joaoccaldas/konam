# Release Proof Board

The release program is intentionally compressed to four states.

## PHONE
A stranger can use the exact deployed URL on real Android and iPhone.

Required evidence:
- fresh browser landing
- onboarding steps
- reveal
- Enter KONA
- Home
- PWA install/relaunch
- safe areas and keyboard
- no P0/P1 blocker

## LOOP
The product creates and preserves value.

Required evidence:
- RaceIdentity survives reload
- returning Home says Continue your Kona
- Discover → Artifact works
- Artifact → Garage works when Garage runtime lands
- state survives relaunch

## PULSE
The product is useful during Kona race week.

Launch scope:
- countdown
- 3–5 sourced/timestamped official or practical cards
- 5 high-quality places
- one fresh story/artifact
- no feed/RSS platform required

## PROOF
Claims require evidence.

Release dashboard measures complete journeys, not commits:
- new user → RaceIdentity → Home
- reload → Continue
- Discover → Artifact
- Enter 3D → Inspect → Return
- share → friend → Build Yours

No capability is marked complete from a schema/contract alone.
