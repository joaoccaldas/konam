## Full-app findings still requiring work

1. **World GPU cost is the highest remaining performance issue.** Mac Chrome
   viewport measurements of the existing world reported phone/low Hall at 1,103
   draw calls and 4,550,462 triangles; desktop/high Hall at 2,615 and 12,820,190;
   desktop Against the Clock at 2,915 and 7,110,036. Repository targets are eco
   80/180,000 and high 160/650,000. These are scene measurements, not certified
   phone FPS. Add bounded room visibility/LOD and batching, then measure the same
   routes before release. The UI changes do not solve this world budget gap.
2. **Doors need further architectural convergence.** The 14 founding catalog
   entries currently map to eight distinct 3D targets plus four page targets;
   Hall and Plan have multiple entries. This is a visible migration bridge, not
   fourteen bespoke 3D rooms. Keep catalog labels and destination behavior aligned
   before creating additional doors. Candidate Beast Cave/Norwegian Engine room
   packages validate but are not publicly wired.
3. **Renderer/asset duplication remains.** Authority inventory has 12 repository
   constructors, 10 browser/5 legacy public authorities and one shared kernel.
   Legacy modern/heritage viewer HTML still embeds GLB payloads (~3.0–3.7 MB per
   page). Baseline tracked assets total ~106.9 MiB; 29 exact-duplicate groups have
   ~19.9 MiB of extra copies, largely generated/public/native packaging. No files
   were deleted. Do not delete packaging copies without checking consumers and
   reproducible staging.
4. **News availability and editorial depth.** The live probe on 5 October found
   all three news/island sources fresh and none of six video sources fresh. One
   direct YouTube RSS probe returned 404. The UI identifies retained video
   snapshots. Current edge providers primarily supply titles, not article bodies;
   editions are source digests, not fabricated AI summaries. Publishing a blog
   still needs an editorial policy and a defined public archive authority. The
   scheduled job prepares review artifacts; it does not publish a blog or commit
   snapshots automatically. Existing RSS channel metadata still points at the
   legacy origin and should be reconciled in the origin-convergence change.
5. **Native and real-device evidence.** Generated web/native packaging, manifest,
   install guidance and standalone flows are checked. No physical iOS/Android
   device, APK hardware run, sustained thermal/battery test or accessibility
   assistive-technology session was performed. Next: real-device touch/scroll,
   safe areas, keyboard, offline updates, orientation and GPU profiling.

Keep retention focused on the triathlon/Kona niche: a short current reading
edition, meaningful discoveries, bike/story details, race preparation and a clear
next action. Further work should make these useful before adding more menus or
reward currencies. Each improvement needs before/after evidence and preservation
of guest use, optional account backup and legacy progress.

brand, integration contract, bike/world and candidate-room validation passed.

tokens and zero JavaScript style injectors. Entry core decreased from 248,553 to
238,855 bytes (gzip 73,597 to 70,622); WebGL remains absent from the entry bundle.

Plan, Me, empty/owned collection, item detail/3D, Intern and Travel. Local checked
viewports are 320×568, 390×844, 844×390 and 1440×900 in light, dark and random

found 42 composition issues in 48 records; corrected captures report zero
detected horizontal/control spill or covered utility controls. This scanner is
bounded and is not a substitute for visual review or full accessibility testing.

load/retry and navigation during loading. All five collectible previews show zero
idle draws under reduced motion, redraw on drag and dispose when left. The mobile
journey also verifies a single persisted Find reward, loaded image and origin-aware
return. Supabase backend/auth/schema were not changed; edge-handler Deno tests
were not included (their old test configuration reference is absent).
