## Release rule

A capability is READY only when:
- implementation exists
- automated checks pass
- runtime/visual evidence exists where relevant
- no known P0/P1 blocker remains
- exact build state is known
- privacy/security boundaries are documented

## Privacy rule

This repository is public. Do not commit:
- private user information
- personal addresses, email conversations, health information, contact lists, private CRM data
- secrets, private tokens, credentials, API secret keys
- private race-history matches or user profiles

Only public product/business/engineering information belongs here.
