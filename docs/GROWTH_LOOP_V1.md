# Growth Loop V1

## Principle
Sharing must carry identity/value, not spam.

## Loop
RaceIdentity reveal → share setup → friend opens setup → Build yours → friend creates RaceIdentity.

## Channels
Primary: Web Share API, which lets the operating system expose installed share targets.
Fallback: copy link.
Explicit convenience: WhatsApp deep link.

Instagram, TikTok and Facebook should normally be reached through the native share sheet or downloadable share-card media rather than brittle private URL schemes.

## Rewards
- No credits merely for pressing Share.
- No credits for opening a referral.
- Future REFERRAL_ACTIVATED reward occurs only after a referred user completes a valid RaceIdentity, with abuse controls/server authority.
- Share and affiliate clicks never alter product ranking.

## Metrics
- reveal → share intent
- successful native share / copied link
- shared-link open
- shared-link → Build yours
- Build yours → RaceIdentity complete
- referred RaceIdentity → optional registration
