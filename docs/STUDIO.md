# The studio — `Studio.html`

One page for every product. Models are fetched when chosen (never inlined), so the page is ~770 kB
for 29 bikes where the old per-bike studios were ~3 MB each. The six engineering studios
(`Speedmax_*_Museum.html`: exploded parts, workshop, aero lab) stay as the "Engineering studio"
deep dive for the Canyon bikes they cover.

## What a visitor can do

| Tab | |
|---|---|
| **Bikes** | search and filter all products (Canyon current, archive, champions, named machines, type studies, studio-only designs, ♥ saved); an event puts its featured bikes first |
| **Paint** | the bike's liveries, *My liveries*, mix your own (frame, accent, rims, disc, tape, saddle — only the slots the model has), finish (gloss / satin / matte), save |
| **Themes** | the eight Bike Porn films (dye + scene + title card) and the museum looks (WYLD dyes, theme rooms, Lava Night) |
| **Scene** | Studio, Kona dusk, Lava field, Night, Velodrome |
| **About** | the shared card engine: facts with evidence classes, reference photo, sources, links to the engineering studio and the museum |

Floating buttons: **✦ Dream** (letterboxed crane shot with the film's title card), **♡** favourite,
**≡** panel. **Share** captures the view with a caption and sends it to any app; the link carries
the look (`?p=&s=&scene=&event=`), validated on the way in (`studio/model.js decodeLook`).

## Data

- `museum/catalog/products.json` — generated by `node tools/build_catalog.mjs` from the museum
  catalogue, viewer profiles, Kona-years build records and `museum/atlas/bikes.json`. Every product
  lists its `sources`. Never edit it by hand.
- `museum/themes/films.json` — the films (also used by the Sanctuary).
- `museum/events/*.json` — an event is a lens: featured products, themes first, share line, accent.
- `museum/skins/museum.json`, `museum/wyld_room.json` — museum looks.

## Scaling

- **A new product:** make a GLB that follows the asset contract (`docs/ARCHITECTURE.md`), add it to a
  source the generator reads (or a new source), run the generator. Studio-only designs: add to
  `museum/atlas/bikes.json` with `"museum": false, "studio": true`.
- **A new brand:** products carry `brand`; filters and search pick it up.
- **A new event:** drop a file in `museum/events/`; open `Studio.html?event=<id>`.
- **Another product type:** products carry `type`; the paint panel only offers the slots the model has.

Build: `node tools/build_catalog.mjs && node web/build_studio.mjs && node tools/harden_pages.mjs`.
Tests: `web/test/studio.test.mjs` (catalogue completeness, more bikes than the museum, link round trip,
hostile links, filters, events).
