This file is the handover for the Kona hall, the upper-floor rooms, and the Kona-generation bikes. It records what was checked and what was not. Do not treat an unverified row as done.

## What this branch is

The hall is a walkable Kona-coast museum. The live page is root `index.html`, built from `web/landing.template.html` and `web/src/landing.js`.

This commit also completes a merge that was sitting unresolved. Incoming commit `3cfc80e` (“Speedmax Nights and History Lane”) added standalone experiences (`Experiences.html`, `web/src/exp/`, `web/src/passport.js`, `museum/history.json`). The five unmerged paths (`index.html`, `manifest.webmanifest`, `sw.js`, `web/landing.template.html`, `web/src/landing.js`) had no conflict markers left in the working tree. The working copies were kept: they contain the hall, the galleries, and the theme-room bikes, and the experience files stay as their own pages.

GitHub Pages (`/.github/workflows/pages.yml`) publishes **only `main`**. This handover does not merge to `main`. Production is unchanged until that merge.

## Build and serve

```bash
node web/build_landing.mjs
node tools/harden_pages.mjs
python3 -m http.server 8754 --bind 127.0.0.1
```

Hard-refresh if an old service worker is stuck. The shell cache name is `canyon-museum-shell-v5` (network-first). A query such as `/?v=rooms-filled3` avoids a stale document.

Blender for the Kona studies: 5.2.2. Run it outside a sandbox (Metal segfaults inside one):

```bash
blender -b --factory-startup --python-exit-code 1 -P blender/kona_years_build.py
```

Outputs: `assets/kona-years/bikes/cfslx-2015/speedmax_web.glb`, `assets/kona-years/bikes/cfr-2019/speedmax_web.glb`, `assets/kona-years/finds.glb`.

### What changed

- **Culling** (`landing.js` frame loop, `galleries.update`). Each theme room is now its own group (`spot.group`), and its CFR is parented to it. Inside a room only that room draws; in the nave, the rooms whose openings are near; downstairs, none. Upstairs the Sanctuary and Lava Night are hidden. Room animation runs only for visible rooms.
- **Stuck walk fixed** (open item from the audit). A waypoint now counts as blocked when the distance to it stops shrinking for 0.6 s, whether or not one axis is still sliding. It only applies while the path is steering (keyboard/stick input never trips it). Upstairs routes use a lane at `x = 13.6` (`NAVE_LANE`), clear of the bay plinths at `x = 11.15`.
- **Rail chips** for the rooms are in reading order: Bio, Horror, Alien, Zombie (were reversed).
- **Rooms rebuilt** (`web/src/galleries.js`, new `web/src/roomkit.js` with seeded canvas textures and drifting motes). No downloads; everything is drawn at load.

  - Alien: rings raised above the bike (`Y + 2.55…3.4`) turning like a gyroscope, ribs rebuilt to arch wall to wall inside the room (fixes the bleed into Zombie), a scan disc that sweeps through the frame, hex deck, panelled walls, glyph panel (not any language), floor halo, drifting points.

- **Room sound** (new `web/src/roomSound.js`). With Sound on, each room has a synthesised bed (Bio: hum, leaves, drips; Horror: beating drone, bulb buzz, heartbeat; Alien: drifting fifths, swept air, pings; Zombie: wind, lamp hum, groans). The sea fades upstairs. Crossfades on the room you stand in.

Regions with no door entry (sanctuary, stair, art-world portals) got `NaN` and hid every hall bike while you were still looking into the hall. WYLD bikes showed from the hall only at `x < 3`, so they popped out as you crossed the aisle. Now hall bikes hide only upstairs, in a walled side room away from its door, or deep on the pier. WYLD bikes show from anywhere downstairs south of `z = −14` except the champions room. **Not re-walked.** If bikes still vanish, note the room and position (`__museum.P`).
